# Villoh's Scoop Bucket

Custom [Scoop](https://scoop.sh) bucket for apps by Villoh.

## Usage

```powershell
scoop bucket add villoh https://github.com/Villoh/scoop-bucket
scoop install villoh/tunnel-agent
```

## Apps

| App | Description |
|-----|-------------|
| [tunnel-agent](bucket/tunnel-agent.json) | Desktop UI for CLIProxyAPI and Perplexity WebUI Scraper. Manage OAuth providers, API keys and session accounts, then point any coding agent at the local endpoint |
